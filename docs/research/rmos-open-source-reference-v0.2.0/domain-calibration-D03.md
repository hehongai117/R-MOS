- 日期：2026-08-30

## 对象边界

本域的软件候选包括控制框架、车队协调框架和运输控制系统。它们只能在“R-MOS 只借适配器与状态契约设计”这一预定使用方式下比较，不能按整套替换能力互排。

VDA 5050、OPC UA Robotics、ISO 13850 和 ISO 3691-4 是规范证据，不参加 OSS 100 分评分。

## 校准规则

- 业务匹配重点：型号/实例/能力分离、适配器边界、错误与状态语义；
- 架构质量重点：调用方向、可替换性、状态所有权、失败隔离；
- 活跃度只按固定的有意义提交、发布、贡献者和 issue/PR 抽样评分；
- “状态为 emergency”不等于可执行急停；“取消订单”不等于安全停止；
- 任何依赖 ROS 2/JVM 全栈的部署方案，在当前单机 Python/FastAPI 边界下必须如实计入成本；
- 安全边界必须由适用标准、厂家安全层和风险评估确定，软件协议只承担观测、抑制、协调和审计责任。
