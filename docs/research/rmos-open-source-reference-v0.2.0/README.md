## 当前结论

本目录纠正了旧版中三类实质错误，并恢复了被裁掉的研究分母，但 **R0 尚未完成**：

1. VDA 5050 的 `cancelOrder` 只是业务协议中的协调取消，不是安全急停，也不保证所有动作被取消后都报 `FAILED`；
2. openTCS 的 `LICENSES/` 中存在某许可证文本，不能证明该许可证实际映射到项目文件；固定提交的 `REUSE.toml` 未发现 LGPL 映射；
3. 旧版只凭 `last_push` 判 OSS-G4 的结论全部撤销，新版只接受固定提交、稳定发布或维护组织声明；
4. D-01、D-02、D-05、D-06、D-07 不再被无批准裁剪，全部恢复为未完成研究域；
5. 六个软件候选均因 OSS-G5 目标版本级安全与供应链证据不足而不具备 100 分评分资格；两个规范对象单列，不参与 OSS 排名。

因此，本目录可以作为下一轮补证的事实底稿，不能作为 R1 的绑定性输入。只有 A6 与 R0 分别重新批准后，R1 才能开始。
