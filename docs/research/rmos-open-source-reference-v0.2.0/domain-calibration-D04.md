## 对象边界

本域只比较开源版本中可固定到源码或正式文档的能力。ThingsBoard 的 PE 描述不得作为 CE 能力证据；商业版、云托管版和当前研究的开源源码必须分开。

## 校准规则

- 业务匹配重点：设备身份、对象订阅、租户/对象隔离、当前与期望状态、跨实例广播；
- 架构质量重点：状态所有权、消息流向、策略执行点和水平扩展边界；
- 单校单机部署是成本基准，分布式 JVM 平台的复杂度必须在运行与学习成本中体现；
- 厂商或项目自述不能替代固定 CE 源码、版本文档和负向授权证据；
- 实时与租户功能只能作为设计参考，不能自动证明 R-MOS 的 M-03、M-12 或 M-19 已关闭。
