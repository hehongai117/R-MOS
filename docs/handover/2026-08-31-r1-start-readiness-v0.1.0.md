## 4. 最短合规启动路径

1. 董事会先按治理闭环包批准 A0～A6 的定向重开；
2. 完成七套 M-AUD-06 的董事会改题、原始答题和独立评分；
3. 为八个 P0 保存主通道与备用通道的真实送达回执；
4. 单独批准只读数据库/运行路由/前端入口指纹探针，补齐 AG-04/AG-05；
5. 继续完成 R0 八域的分页饱和、固定版本、许可证/安全、深研、淘汰和独立评分；
6. A0～A5 依次重新批准后重发 A6，再由董事会批准 A6；
7. R0 独立批准后，才把 R1 状态从 BLOCKED 改为 READY。

## 5. 禁止的捷径

- 不得用本轮 `22 passed` 或 973 项回归替代 M-03、RT-GATE、数据库门禁或 A6 批准；
- 不得把五域第一轮发现写成搜索饱和或 R0 完成；
- 不得由整改执行者伪造独立答题、独立评分、董事会批准或外部送达回执；
