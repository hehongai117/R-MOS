## 一、产品概述

R-MOS 是面向职业院校机器人类专业的**机器人维保实训平台**，以"数字孪生 + AI 智能体 + 标准化作业裁决"为核心，实现教师上传机器人资料 → AI 自动生成教学内容（标准作业规程 SOP、3D 数字模型、故障案例库）→ 学生在数字孪生环境中标准化实训 → 系统自动裁决评分并生成五维技能画像的完整闭环。

平台采用**多机器人可插拔架构**，支持人形机器人、协作机械臂、灵巧手、四足机器人等多种机型；采用**全 Web 化 B/S 架构**，师生通过浏览器即可使用，无需安装客户端。

## 八、待确认清单（提交招标前必须核实，避免虚标风险）

> 以下三类为投标应答中的**高风险项**，务必由贵方按真实情况确认后再填入正式标书。

### 8.1 性能量化参数 ⚠️
- **现状**：系统架构为异步高并发设计、遥测 5Hz 实时推送，但**尚未进行正式压力测试与性能基线采集**。
- **应对建议**：
  - 若招标文件要求填写并发数/响应时延等硬指标 → 建议在部署验收环境实测后填写真实值，或注明"以现场测试验收为准"。
  - 平台已内置性能测量工具（首屏加载、WebSocket 时延、3D 渲染、AI 管线计时），可在中标后现场采集。
  - **切勿凭空填写并发/TPS/时延数字**——虚标在验收阶段无法兑现将构成违约。

### 8.2 真机联动范围 ⚠️
- **现状**：当前版本以**数字孪生仿真实训**为核心，机器人交互由仿真适配器模拟；系统已预留真机接入的标准适配器扩展接口（`BaseRobotAdapter`），但**尚未实现真实物理机器人的实时控制**。
- **应对建议**：
  - 若招标定位为**虚拟仿真实训 / 数字孪生实训**（多数职教维保实训场景）→ 本产品完全匹配，且"纯软件、零真机损耗、可无限次演练"是优势卖点，可正面表述。
  - 若招标明确要求**真机联动/软硬件一体**→ 需与贵方确认是否配套真实机器人硬件及集成范围，据实应答，不可将"仿真"表述为"真机控制"。

### 8.3 商务与硬件参数 ⚠️
- 服务器硬件配置、软件授权模式（并发授权/站点授权）、部署实施、培训、质保售后（第七章）均取决于贵方商务方案，需据实填写。
- 建议同时确认：数据本地化要求（校内数据不出校/不出境）、等保合规要求（如涉及）、AI 大模型的部署形态（云端 API / 本地私有化模型——本地化部署需额外算力）。

## 九、竞争优势提炼（供技术分陈述参考）

1. **多机器人可插拔平台**——一套系统覆盖多机型，教师自主上传扩展，非"一机一系统"的封闭方案。
2. **AI 自动生成教学内容**——上传资料即自动产出 SOP/3D/故障库，大幅降低教师备课成本。
3. **智能裁决引擎（自主核心技术）**——操作步骤级自动裁决评分，替代人工逐一批阅。
4. **五维技能画像**——量化学生能力短板，支撑精准教学。
5. **通用 3D 数字孪生**——WebGL 浏览器原生渲染，零客户端安装，URDF 自动建模。
6. **工程质量可验证**——1200+ 自动化测试 + CI 门禁，非"演示级"原型。
7. **不锁定供应商**——存储/大模型/部署均可切换，开放架构。
