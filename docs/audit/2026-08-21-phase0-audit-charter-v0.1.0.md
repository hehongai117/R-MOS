- 日期：2026-08-21
- 状态：Phase 0 基线已建立；Phase 1 待确认

- 审查分支：`codex/architecture-audit-phase0`

## 1. 目标

本阶段只建立一套可重复、可追溯的审查方法，回答三个问题：

1. 后续审查应以哪些当前材料和代码为依据；
2. 哪些结论只是历史记录、设计目标或尚未验证的声明；
3. 在不碰生产代码、不启动服务、不改数据库的前提下，是否具备进入正式审查的条件。

本阶段不评价系统已经“安全”“可上线”或“验收通过”。

## 2. 完成标准

Phase 0 只有同时满足以下条件才算完成：

- 固定审查提交、分支和工作目录；
- 现行、归档、缺失和相互冲突的事实源均有登记；
- 规定结论格式、证据等级和复核方式；
- 明确下一阶段的审查链路和停止条件；
- Claude Code 至少完成一次真实只读样例；若无法完成，必须留下真实失败结果并标为不可用；
- 变更仅限审查文档和开发记录；
- 文档链接、编号、差异和仓库状态经过实际检查；
- 形成一个独立提交，不推送。

## 3. 审查边界

### 本阶段包含

- 读取当前代码、配置、文档和 Git 历史；
- 固定基线并在隔离工作区记录结果；
- 标出规则缺口、材料冲突和环境前置条件；
- 给出 Phase 1 的进入门槛。

### 本阶段不包含

- 修改应用代码、测试代码、依赖、数据库或运行配置；
- 启动前端、后端、数据库、浏览器或真机；
- 恢复被删除的旧规则文件；
- 把旧测试数字当作当前测试结果；
- 作出正式上线、真机验收或课堂交付结论；
- 推送远端分支。

## 4. 事实与证据规则

### 4.1 结论类型

每条正式发现只能属于以下一种：

| 类型 | 含义 | 写法要求 |
|---|---|---|
| 事实 | 当前代码、配置、命令输出或可定位历史直接证明 | 必须给出路径、提交或可复现命令 |
| 推断 | 多项事实共同支持，但尚未直接验证 | 明确写“推断”，并给出验证办法 |
| 未知 | 证据不足、环境缺失或需要外部信息 | 不猜测，不降格成“基本可用” |

### 4.2 证据等级

| 等级 | 证据 | 可以支持的结论 |
|---|---|---|
| E0 | 计划、说明、注释、历史报告 | 说明目标或历史状态，不能证明当前行为 |
| E1 | 当前静态代码、配置、数据结构、Git 历史 | 证明当前结构或变更来源，不能替代运行结果 |
| E2 | 当前提交上的自动测试、接口调用、浏览器操作及原始输出 | 证明对应软件路径在该环境的实际表现 |
| E3 | 预生产故障演练、性能、恢复、断网与安全证据 | 支持非功能门禁结论 |
| E4 | 真机和真实课堂记录 | 支持设备交付与课堂验收结论 |

低等级证据不能代替高等级证据。测试通过也不能自动证明权限隔离、故障恢复或真实机器人安全。

### 4.3 正式发现格式

每条发现至少包含：

- 编号和审查链路；
- 事实、推断或未知；
- 影响等级 P0 至 P3；
- 当前证据及其等级；
- 对当前用户和后续扩展的影响；
- 最小处理方向；
- 可复现验证方法；
- 独立复核状态。

没有证据的判断不得列为已确认问题。修复建议与事实本身分开记录。

## 5. Phase 1 六条审查链路

若用户批准进入 Phase 1，按风险优先执行：

1. **身份与对象归属**：登录、角色、跨用户、跨教师、跨学校访问及拒绝审计。
2. **任务与机器人控制**：任务归属、机器人绑定、状态切换、停止与重复命令。
3. **SOP、裁决与证据**：步骤门禁、结果落库、报告一致性、缺失证据和串会话风险。
4. **AI、审批与审计**：AI 只建议不直控、写操作审批、`trace_id` 链路和引用访问控制。
5. **遥测与实时通道**：WebSocket 认证、按机器人订阅隔离、断线重连和消息越界。
6. **部署、恢复与交付**：配置来源、备份恢复、断网运行、性能门槛、真机与课堂证据。

每条链先做静态映射，再决定是否需要当前环境的运行验证；不能用一个局部测试替代整条链的结论。

## 6. 安全底线

在新的验收章程得到确认前，以下底线继续作为更保守的执行约束，而不是“已通过”结论：

- AI 直接发起真实机器人动作必须为 0；
- 有副作用的写操作必须经过明确批准并留下审计；
- 越权读取按对象归属拒绝，拒绝本身也必须可审计；
- 命令、调用、批准和审计必须能用同一追踪标识串联；
- 引用和证据必须验证存在性及访问权限；
- 没有预生产恢复演练、真机安全证据和课堂证据，不得宣称可生产交付。

这些约束来自当前最高规则文件和被删除验收章程的共同安全意图；旧章程只作为历史证据，不作为当前完整验收标准。
