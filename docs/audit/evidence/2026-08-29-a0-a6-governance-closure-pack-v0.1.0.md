## 2. AG-02 / M-AUD-06 执行规则

每阶段都必须完成以下六步：

1. 主审提交 10 道候选题；
2. 董事会在密封状态下批准题目，并独立新增或替换至少 3 题；
3. 非主审的新会话答题，不得预先看到答案与评分表；
4. 保留逐题原始回答，不允许先润色再归档；
5. 非主审评分者按冻结标准逐题评分并说明扣分；
6. 记录答题者、评分者与主审的身份及独立性，只有 10/10 且无关键歧义才可 PASS。

统一原始记录字段：

| 字段 | 必填内容 |
|---|---|
| Stage / Report | 阶段、报告版本、提交 |
| Board-approved questions | 用户批准的最终 10 题原文 |
| Board replacements | 至少 3 道由董事会新增或替换的题及编号 |
| Frozen rubric | 每题正确要点、关键错误、通过阈值 |
| Raw answers | 新会话逐题原文 |
| Score sheet | 每题 0/1、依据、总分 |
| Actors | 主审、答题者、评分者 |
| Independence | 三者关系及隔离方式 |
| Final result | 10/10 PASS 或返工；签名和时间 |
