## A3 历史结论（已被 0.2.0 订正）

## A4 历史结论（已被 0.2.0 订正）

认证边界在 `/api/v1` 内成立（默认拒绝网关 + 7 条白名单 + 嵌套 router 全覆盖），但网关只作用于该前缀——`/`、`/openapi.json`、`/docs`、`/redoc` 匿名可达，完整接口契约对外公开。

机器人控制与急停在系统层面不存在，A4 要求覆盖的命令状态机、停止与真机边界记为 MISSING。`PolicyMatrix` 只覆盖 AI 路径，46 条无隔离写操作零风险评级。`auditor` 角色拥有审批处置权，违反职责分离。
